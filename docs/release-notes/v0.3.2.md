LoopCtrl 0.3.2：修好系统录屏推流——它现在真正接管画面，开启后点击也不再偏移；控制页在窄屏上完整显示状态行。中继继续用 server-v0.3.0，Pair 不变。/ Fixes System Broadcast — it now actually takes over the picture, and taps are no longer offset while it runs — and gives the control page's status line its own row on narrow screens. The relay stays at server-v0.3.0; Pair is unchanged.

### 🐞 修复 / Fixes

- **系统录屏推流真正生效**：扩展连上以后，runner 在收到 hello 之前没有持有这个连接，对象被释放，握手永远完不成——日志里只有 connected，没有 started，画面一直还是截图。现在连接会被持有到握手完成（被新连接替换或提前关闭时也会清理）/ **System Broadcast actually takes over**: after accepting the extension's connection the runner did not retain it until its hello arrived, so the handshake never completed — the log said "connected" but never "started", and the picture stayed on screenshots. The connection is now held until hello, and cleaned up when replaced or closed early
- **开启录屏后点击不再偏移**：扩展把 ReplayKit 已经缩放的视频缓冲（884×1920）当成屏幕像素除以 3，上报的点击空间是 294×640，而真实屏幕是 402×874；于是点右下角会落在左上。现在点击空间取 `UIScreen.nativeBounds / nativeScale`，只在画面旋转时交换宽高 / **No more offset taps with broadcast on**: the extension treated ReplayKit's already-scaled buffer (884×1920) as screen pixels, so it reported a 294×640 tap space instead of the real 402×874, and taps landed up and to the left. The tap space now comes from `nativeBounds / nativeScale`, swapping axes only when the picture is turned
- **窄屏顶栏不再裁掉状态行**：宽度 ≤760px 时状态行独立成第二行；≤375px 时与人数胶囊同排；≤340px 隐藏人数胶囊；横屏仍保持单行 / **The status line is no longer clipped on narrow screens**: at ≤760px it gets its own row under the bar; at ≤375px it shares that row with the people pill; at ≤340px the pill is hidden; landscape stays one row
