LoopCtrl 0.3.0：合并仓库后的首个正式 tag，版本号与中继（server-v0.3.0）、Pair（pair-v0.3.0）统一。主打新功能：通过中继或局域网直接从浏览器远程控制 iPhone。/ The first tagged release of the merged repository, with version numbers unified to 0.3.0 across the app, the relay (server-v0.3.0) and Pair (pair-v0.3.0). Headline: control the iPhone from a browser, through the relay or directly on the LAN.

### 🔧 改进 / Improvements

- **浏览器远程控制**：手机保持一条到中继的 WebSocket 隧道，浏览器打开手机的公共地址（`…/d/<slug>/`）即可控制，与局域网直连同一套 `/remote` 控制页和 `/rpc` 接口（见 [remote-control.md](https://github.com/Souitou-iop/LoopCtrl/blob/main/docs/remote-control.md)）/ **Browser remote control**: the phone holds one WebSocket tunnel to the relay; opening the phone's public address (`…/d/<slug>/`) in a browser gives the same `/remote` control page and `/rpc` API as the LAN
- **版本统一**：app、中继、Pair 三端从本版本起使用同一版本号迭代 / **Unified versioning**: the app, the relay and Pair share one version number from this release on
- 中继配套：本版本需要支持 `loopctrl-tunnel-v1` 的中继（`server-v0.3.0` 起）才可远程；旧中继只影响远程功能，USB 直连不受影响 / Relay requirement: remote control needs a tunnel-capable relay (`server-v0.3.0` or later); USB pairing and LAN control are unaffected
- **控制页功能区去掉「锁屏」和「唤醒」**：锁屏对浏览器这一侧没有可见收益；`unlock` 只能按 Home 键，设有密码时进不去，而它把「真的解锁」当作成功条件，于是白等几秒报超时。RPC 的 `lock` / `unlock` / `is_locked` 不变，无密码的无人值守测试机照旧可调用 / **The control page's tool rail no longer carries Lock and Wake**: locking gains the browser operator nothing, and `unlock` only presses Home — with a passcode set it can never meet its own success test, so it waited out and timed out. The `lock` / `unlock` / `is_locked` RPCs are unchanged, as before for unattended test devices without a passcode
- 中继连接详情页两行同栅格：控制地址落在标题那一列，复制 / 分享落在值那一列的右边缘 / **The relay connection detail rows share one grid**: the control address sits in the title's column, copy and share on the value's trailing edge
