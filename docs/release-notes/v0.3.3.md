LoopCtrl 0.3.3：补齐四个设备功能——实体音量键、剪贴板、保持唤醒、系统截图；控制页的工具条改成可自由排序。中继继续用 server-v0.3.0，Pair 不变。/ Four device features — real volume keys, clipboard, keep-awake and system screenshots — plus a freely sortable tools rail on the control page. The relay stays at server-v0.3.0; Pair is unchanged.

### ✨ 新增 / New

- **音量键**：控制页工具条上的音量 + / −，按的是手机的真实媒体音量键（`XCUIDevice.press`），返回只代表按键已发出 / **Volume keys**: the volume + / − buttons press the phone's real media buttons (`XCUIDevice.press`); the reply says the press went out, not what the level became
- **剪贴板**：把电脑上的文字发到手机剪贴板，或读取手机复制的文字。iOS 只允许 App 在前台时读写剪贴板，所以读取/写入时 LoopCtrl 会短暂切到前台，做完再切回原来的 App；文字不会写进日志 / **Clipboard**: send text to the phone's clipboard or read what it copied. iOS only allows this while the app is in the foreground, so LoopCtrl comes forward briefly and goes back afterwards; the text is never logged
- **保持唤醒**：每 10 秒按一次 iOS 不认识的 F13，最长 60 分钟，锁屏时自动跳过；适合长时间无人值守 / **Keep awake**: F13 (a key iOS ignores) every 10 s for up to 60 minutes, skipped while locked, for long unattended runs
- **系统截图**：触发和实体键一样的系统截图，iOS 存进相册。返回只代表事件已发出，需要自己去 Photos 确认 / **System screenshot**: sends the same key as the hardware shortcut; iOS saves it to Photos. The reply means the event went out — check Photos to confirm

### 🔧 改进 / Improvements

- **工具条可自由排序**：所有功能是一个有序列表，前 5 个常驻工具条，其余进「更多」；「更多 › 排序按钮」里用 ↑ ↓ 调整，分隔线以下自动进「更多」，顺序存在当前浏览器；宽且高的窗口直接展开全部 / **Freely sortable tools rail**: one ordered list, the first five stay on the bar and the rest go into More; More › Sort buttons moves them with ↑ ↓, the divider marks where More starts, and the order is kept per browser; a wide, tall window shows the whole list
- 剪贴板和系统截图从设置移到工具条（在「更多」里），设置里只留「保持唤醒」 / Clipboard and System screenshot moved from Screen settings into the tools area (More); Screen settings keeps Keep awake
