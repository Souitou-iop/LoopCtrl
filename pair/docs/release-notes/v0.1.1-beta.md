LoopCtrl 配对助手 0.1.1 测试版：新增 Linux 桌面版和命令行版，安装包改由 GitHub Actions 构建。

## 新增

- **Linux 桌面版**（x86_64、aarch64 `.deb`）：同样的 miuix 界面。有系统 usbmuxd 就用它；没有就用内置 usbmuxd 直接访问 USB（不附带任何 GPL 组件）。环境检查会显示系统 usbmuxd、内置模式、udev 规则和 USB 访问状态；没有权限时可一键安装 udev 规则（pkexec），系统 usbmuxd 占用 iPhone 时给出说明并自动改用它。`.deb` 自带 udev 规则。
- **命令行 `loopctrl-pair`**（Linux、macOS、Windows）：`devices`、`pair`（`--all` 批量）、`write`、`verify`、`env`、`udev-rule`，支持 `--json`，适合自助机和树莓派。
- **外接硬件预留**：usbmux 传输层可以通过 TCP 接收外接 USB 桥（例如 ESP32-S3）转发的 iPhone（`--bridge-listen`）。设计见 `docs/hardware-helpers.md`，固件尚未编写。

| `LoopCtrl-Pair-0.1.1-macos-universal.dmg` | macOS 12+（Apple Silicon 和 Intel） | 未签名、未公证：首次打开请在 Finder 里右键 › 打开 |

| `LoopCtrl-Pair-0.1.1-android-debug.apk` | Android 8+（需要 USB OTG） | Debug 签名的测试包 |
| `loopctrl-pair-cli-0.1.1-*` | 命令行 | Linux x86_64 / aarch64、macOS、Windows |

Linux 用 `.deb` 或命令行压缩包安装。不提供 AppImage：它会把 LGPL 的 GTK / WebKitGTK 打包进去；`.deb` 使用发行版自带的系统库。

## 已验证

- 所有平台的安装包由 CI 构建；Linux 上运行了全部 Rust 测试和命令行模拟流程（配对、写入、校验），内置 usbmuxd 在真实 Linux 内核上启动并提供 socket。
- 0.1.0 中 macOS + iPhone（iOS 27.2）的完整流程不受影响。

## 尚未验证 ⚠️

- **Linux + 真 iPhone**：内置 usbmuxd 的 USB 配置切换、认领接口、usbfs 传输、udev 规则、与系统 usbmuxd 冲突的检测，以及 Linux 桌面版界面本身，都只在 CI 中构建、未在真机上运行。
- aarch64（树莓派）安装包只构建，未运行。
- Windows 安装包第一次由 CI 构建，未在 Windows 上运行。
- ESP32 外接桥：只有电脑端和协议（用模拟设备测试），没有固件和硬件测试。
- 0.1.0 中列出的未验证项仍然有效（首次「信任」弹窗、开发者模式引导、iOS 16 / 17.0–17.3 真机、LoopCtrl 导入、Android 真机 OTG）。
