LoopCtrl 配对助手 0.2.0 测试版：重做界面，一台和多台走同一个流程。

## 新界面

不再区分「单台」和「批量」。电脑版和安卓版都改成同一个流程：

1. **自动识别**：插上的 iPhone 会自动列出（型号、iOS 版本、USB 口），显示「读取中」「就绪」或「系统太旧」。此时不会对 iPhone 做任何操作。
2. **开始配对**：按钮显示就绪的数量（「开始配对 3 台」），点一下所有就绪的 iPhone 一起开始；配对过程中再插上的 iPhone 自动加入。
3. **每台各自提示**：每台 iPhone 的卡片里直接写着要在手机上做什么（点「信任」、打开开发者模式、等重启、点「打开」），出错时显示原因、解决步骤和「重试」。需要你操作的排在最前面。只有一台时显示五步进度和大图提示。
4. **完成**：全部完成后显示「配对完成」和以后怎么用；点「完成」回到等待，这次配好的 iPhone 列在「本次已配对」里。「停止」会让还没完成的 iPhone 回到就绪状态。

其他变化：

- 环境检查移到顶栏（「环境正常 / 环境异常」），点开看详情；有问题时页面上有红色提示，「开始配对」不能点。
- 设置单独成页，左上角返回。电脑版去掉侧边栏，安卓版去掉底部导航。
- 后端没有变化：同一个 `pair-core`，命令行 `loopctrl-pair` 不受影响。

## 已验证

- macOS 桌面版：用模拟设备走完 1 台和 5 台的开始、信任、开发者模式、重启、出错重试、停止、完成；中英文、深浅色。
- 安卓版（arm64 模拟器，Android 13）：没有 OTG 时的环境提示；模拟设备 1 台和 5 台走完同样的流程；中英文。

## 尚未验证 ⚠️

- **新界面还没有接过真 iPhone**，任何平台都没有。
- Windows 和 Linux 桌面版的新界面只由 CI 构建，没有在这两个系统上运行过。
- 0.1.1 中列出的未验证项仍然有效（Linux 内置 usbmuxd 真机、Windows 安装包、树莓派、ESP32 外接桥、安卓真机 OTG 等）。
