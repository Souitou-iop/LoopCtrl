LoopCtrl Pair 0.3.0：功能与 0.2.1 相同，本版本起版本号与 LoopCtrl 主程序、中继统一为 0.3.0，安卓正式包首次由 GitHub Actions 用发布密钥签名发布。/ LoopCtrl Pair 0.3.0 is functionally the same as 0.2.1; from this release the version numbers of the app, the relay and Pair move together, and the Android release APK is signed by GitHub Actions with the release key for the first time.

### 🔧 改进 / Improvements

- 版本号与 LoopCtrl 主程序（`v0.3.0`）、中继（`server-v0.3.0`）统一为 0.3.0，之后三者一起迭代 / The version number moves in lockstep with the LoopCtrl app (`v0.3.0`) and the relay (`server-v0.3.0`); the three iterate together from now on
- 安卓正式版安装包改由 GitHub Actions 用发布密钥签名（与 0.2.1 同一把密钥，可直接覆盖升级）/ The Android release APK is now signed by GitHub Actions with the release keystore (the same key as 0.2.1, so it installs over it)
- 桌面版与安卓版的构建、签名全部来自合并后的 LoopCtrl 仓库流水线 / Desktop and Android bundles are all built and signed by the merged LoopCtrl repository's pipeline
- 功能代码与 0.2.1 相同：0.2.1 在 Android、Windows、macOS 上用真 iPhone 走通配对流程的结论适用 / No functional code changes since 0.2.1: the real-iPhone pairing runs verified there (Android, Windows, macOS) still apply

## ❓ 常见问题 / FAQ

- 安装安卓正式版前如果装过更早的 debug 包（0.1.x、0.2.0），签名不同需要先卸载；0.2.1 及以后可直接覆盖 / If an APK from 0.1.x or 0.2.0 is installed, uninstall it first (different signature); 0.2.1 and later install over each other
- 安卓版通过 USB OTG 线连接 iPhone，首次连接要在手机上点「信任」/ The Android app reaches the iPhone over a USB OTG cable; tap *Trust* on the iPhone the first time
- Linux 桌面版与命令行、iOS 16 和 17.0–17.3 的旧配对路径尚未接过真 iPhone，其余未验证项见 [0.2.1 说明](https://github.com/Souitou-iop/LoopCtrl/releases/tag/pair-v0.2.1-beta) / The Linux desktop and CLI builds, and the legacy pairing paths for iOS 16 and 17.0–17.3, have not seen a real iPhone yet; other unverified items are listed in the 0.2.1 notes
