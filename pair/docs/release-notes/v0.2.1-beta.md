LoopCtrl 配对助手 0.2.1 测试版：安卓版提供正式签名的安装包，修复设置页的显示问题，并附上全部开源许可证全文。已在 Android、Windows、macOS 上用真 iPhone 走通配对流程。

## 变化

- **安卓正式版安装包**：新增 `LoopCtrl-Pair-0.2.1-android.apk`，用发布密钥签名、按 release 编译（体积约为 debug 版的一半，运行更快）。之后的版本都用同一个密钥签名，可以直接覆盖升级。
  - 从 debug 版换成正式版时，需要先卸载 debug 版（两者签名不同）。
  - debug 版仍然提供（`-android-debug.apk`），带「开发者选项」里的模拟设备，方便测试。
- **安卓设置页**：深色模式下「主题」「语言」两组选项的背景显示成黑块，改为正常的分段选择样式。
- **开源许可**：电脑版和安卓版都附带每个组件的许可证全文（电脑版在「设置 › 开源许可 › 全部许可证全文」）。iLoader 的署名改为「USB 实现」。

## 已验证

三个平台都用真 iPhone 走通了完整流程：信任、开发者模式、生成配对记录、写入 LoopCtrl、校验。

- **macOS 桌面版**：安装并启动，真 iPhone 走通完整配对流程。
- **Windows 桌面版**：安装并启动，真 iPhone 走通完整配对流程。
- **安卓版**（USB OTG，验证用的是 debug 版安装包）：安装并启动，真 iPhone 走通完整配对流程。
- 安卓正式版（arm64 模拟器，Android 13）：安装、启动、内置 USB 服务和环境检查正常；签名校验通过。
- 安卓设置页在深色和浅色模式下的显示。

## 尚未验证 ⚠️

- 安卓正式版（`-android.apk`）还没有在真机上跑过配对流程：真机验证用的是 debug 版，两者是同一份代码，差别只在签名和是否带模拟设备。
- Linux 桌面版和命令行仍未接过真 iPhone，只由 CI 构建、用模拟设备测过。
- iOS 16 和 17.0–17.3 的旧配对路径仍未在真机上验证。
- 0.1.1、0.2.0 中列出的其他未验证项仍然有效（树莓派 aarch64 安装包、ESP32 外接桥；多台 iPhone 同时配对只在模拟设备上验证过）。
